# Source Manifests

Source manifests will record where each document came from, its license, jurisdiction, document type, retrieval date, checksum, and related-document family.

`phase2_validation_sources.json` is the frozen Phase 4 source manifest. It records where each document came from, its license, jurisdiction, media type, checksum, family links, and training eligibility. Rights marked `review_required` and every current validation document remain blocked from training.
