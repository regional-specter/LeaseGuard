# Data Samples

Store small synthetic or clearly reusable examples here so contributors can test the pipeline without downloading the complete dataset.

Current version `1.0.0` examples:

- `lease_extraction.v1.json`
- `document_answer.v1.json`
- `dataset_v1/` — synthetic Dataset v1 seed examples, quality review, and construction inputs

These files are synthetic and are validated against the public ontology and dataset models during tests.
