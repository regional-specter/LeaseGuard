# Security Policy

## Reporting a Problem

Do not open a public issue if a report includes a private lease, personal information, credentials, or a vulnerability that could expose user documents.

Use the repository owner's private security reporting channel when it becomes available. Until then, contact the maintainer privately through the contact method listed on their GitHub profile.

## Sensitive Data

Never submit real private leases, access tokens, personal records, or confidential annotations. Tests and examples must use synthetic or clearly reusable material.

## Current Status

LeaseGuard is in early development and is not ready for production legal work. No released version should be treated as a replacement for professional legal review.
